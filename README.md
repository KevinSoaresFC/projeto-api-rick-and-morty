# 🛸 Universo Rick and Morty - Consumo de API REST

Fala, pessoal! 👋 Este é o meu projeto prático de **Front-End**, desenvolvido para aplicar conceitos de consumo de dados em tempo real (APIs) e manipulação dinâmica do DOM.

## 🎯 Qual foi o desafio?
A missão era construir um site que consumisse uma API pública de desenhos/séries (escolhi a do Rick and Morty) e renderizasse os dados na tela **exclusivamente via JavaScript**. 
A regra principal era: **o HTML deveria estar vazio**. Todos os *cards* de personagens que aparecem na tela foram gerados dinamicamente através do JS!

## 🛠️ Tecnologias Utilizadas
Nenhum framework foi utilizado aqui. O projeto foi construído na base, com:
- **HTML5** (Semântico)
- **CSS3** (CSS Grid, Flexbox e efeitos de neon no hover)
- **JavaScript Moderno** (Async/Await, Fetch API, DOM Manipulation)

## 🧠 O que eu aprendi na prática?
- Utilizar a função `fetch()` e o `async/await` para requisitar dados de forma assíncrona.
- Navegar por estruturas de objetos e arrays `JSON` complexos.
- Criar elementos do zero usando `document.createElement()`.
- Montar a hierarquia visual na tela com `appendChild()`.
- Estilizar e adicionar classes CSS dinamicamente com o JS.

## 🔗 Sobre a API
Os dados são fornecidos pela excelente e gratuita [The Rick and Morty API](https://rickandmortyapi.com/).
